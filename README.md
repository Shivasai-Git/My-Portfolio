# My Portfolio

Shivasai Aillaboina's developer portfolio — a Next.js (App Router) site exported as fully static HTML.

## Run it

```sh
npm install
npm run dev      # development server at http://localhost:4178
npm run build    # static export to out/
npm start        # serve out/ at http://localhost:4178
```

Deploy by uploading `out/` to any static host (Vercel, Netlify, GitHub Pages, etc.).

## Where things live

- `app/page.jsx` — all page content: navigation, learning rows, certificates, journey cards, contact details.
- `app/layout.jsx` — metadata and self-hosted fonts (`next/font`).
- `app/globals.css` — every style, including responsive and reduced-motion rules.
- `lib/portfolio.js` — the animation layer: greeting preloader, pixel-particle portrait, scroll effects, journey shelf, breakout game, smoke background. Loaded client-side after hydration by `components/PortfolioEffects.jsx`.
- `public/images/` — optimized WebP images, generated by `npm run images` from:
  - `source-certs/*.png` — certificates rendered from the original NxtWave PDFs,
  - `source-portrait/` — the original portrait photo and its alpha matte (hero portrait source).
  - `dist/assets/portrait-cutout.png` — the earlier generated cutout, kept for reference.
- `dist/` — the earlier buildless version of the site, kept as the image source and for reference (`npm run preview:legacy`).

## Adding a certificate

1. Render the PDF to `source-certs/cert-<name>.png` (about 2400px wide) and add `cert-<name>` to the list in `scripts/optimize-images.mjs`.
2. Run `npm run images`.
3. Add an entry to `CERTS` (and optionally `JOURNEY`) in `app/page.jsx`, and to the `certs` list in `lib/portfolio.js` for the full-size viewer.
